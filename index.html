Koneksi Supabase

URL dan kunci publik disimpan di LocalStorage browser ini. Jangan gunakan service_role atau secret key.

Akun guru

Akun dibuat oleh teknisi di Supabase Authentication dan ditambahkan ke daftar guru melalui SQL.

Persiapan pertama
  1. 1
    Siapkan tabel dan izin
    Salin isi supabase.sql ke SQL Editor proyek Anda lalu jalankan.
  2. 2
    Daftarkan akun guru
    Buat pengguna melalui Authentication → Users, lalu masukkan UUID pengguna ke tabel school_staff. Nonaktifkan pendaftaran publik.
  3. 3
    Hubungkan aplikasi
    Isi Project URL dan anon / publishable key dari pengaturan Supabase, lalu masuk sebagai guru.

Gunakan HTTPS atau localhost agar izin kamera tersedia. Jika dibuka sebagai berkas dan browser membatasi webcam, gunakan hosting statis HTTPS. Data dan foto wajah hanya dapat diakses oleh akun guru yang diizinkan.
